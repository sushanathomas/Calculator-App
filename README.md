# Simple Calculator

A calculator built with HTML, CSS, and JavaScript that performs
basic arithmetic on two numbers.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Responsive layout for desktop, tablet, and mobile screens

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open index.html in your browser.
2. Enter a number in each input.
3. Click an operation button.
4. View the result below the buttons.

No installation or additional dependencies are required.

## Project Files

- index.html — calculator structure
- calculator.css — styling and responsive layout
- calculator.js — arithmetic and button interactions
- README.md — project documentation

## Current Limitations

Empty inputs are treated as zero. Division by zero may display
Infinity or NaN.
